# 🛒 Smart E-Commerce Price Tracker

A lightweight and efficient Python application designed to track real-time product prices from e-commerce platforms, log historical price trends into an SQLite database, and visualize market changes through an interactive Streamlit web interface.

## 🚀 Key Features
- **Real-Time Web Scraping:** Extracts live product titles and pricing data using `BeautifulSoup` and custom request headers.
- **Historical Data Logging:** Automatically stores price points with timestamps in an embedded `SQLite` database.
- **Interactive Web Dashboard:** Built with `Streamlit` to provide user inputs, success metrics, data tables, and dynamic price trend charts.
- **Data Analytics:** Uses `Pandas` to process and display historical fluctuations over time.

## 🛠️ Tech Stack
- **Language:** Python
- **Web Framework:** Streamlit
- **Web Scraping:** BeautifulSoup4, Requests
- **Database:** SQLite3
- **Data Handling:** Pandas
